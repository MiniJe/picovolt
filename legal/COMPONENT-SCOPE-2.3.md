publication or a license-policy change. This file records implementation scope
only. It does not rewrite root LICENSE, its digest, or historical release grants.

`src/db/persistent.rs`), new retrieval integration/API additions, and their new
tests, fuzz targets, benchmark and documentation follow the existing PicoVolt
Public-Source License 1.1 scope for post-2.0 retrieval components. Existing Apache
code, including the full-text implementation and its notices, retains its prior
grants. Dependency licenses and notices are unchanged. No new dependency is
introduced by this mandate.

The license text's 2.2 effective-release wording remains unchanged. The 2.3 scope
record applies the same existing terms to these additions; it is not a new fee,
commercial restriction, account requirement or grant of third-party rights.

publication requires the separate founder release decision and normal gates.
