# 2.1.0 component and license boundary

This private development line uses the prepared PicoVolt Proprietary Lifetime
License 1.0 for newly authored proprietary work, subject to the scope of an
eventual issued offer. It does not retroactively revoke or replace licenses
already granted. This ledger is not an assertion of cleared ownership of every
historical contribution or dependency.

New 2.1 work comprises `src/vector.rs`, `src/retrieval.rs`, the retrieval entry
points added to the CLI, C ABI, WASM, Python, Go and JavaScript adapters, and
their new tests/documentation. The local full-text implementation is carried
forward with its existing notices. Modified source files identify this change.

Historical source and components distributed under Apache-2.0 retain those
terms. `APACHE-2.0-LEGACY.txt` preserves the full license and root `NOTICE`
preserves attribution. Dependencies retain their own licenses. A private build
dependency inventory accompanies the artifacts; it is not a completed legal
provenance review. Before any customer offer, confirm contributor authority and
the exact component/dependency notice set for that artifact.

The license restricts covered proprietary additions only to the extent the
Licensor can grant those rights. No account, telemetry, remote kill switch or
forced acceptance has been added to legacy builds.
